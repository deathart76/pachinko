# pachinko

웹 기반 3D 파친코 게임입니다. (egoavara/personal-pages 기반 개인 수정판)

배포 주소: https://deathart76.github.io/pachinko/

## 참가자 입력

시작 화면에서 참가자를 직접 입력합니다. 기본 목록은 김사장, 이박사, 박여사, 최회장, 황간첩, 국카스텐 6명(각 공 6개)이며, 입력하지 않아도 바로 시작할 수 있습니다.

- 한 페이지에 14명씩 보이며 `‹ 이전` / `다음 ›` 으로 페이지를 넘깁니다. 인원 상한은 없고, 게임은 공이 있는 참가자 2명 이상부터 시작할 수 있습니다.
- 이름 칸(점선 테두리 + 연필 아이콘)을 눌러 바로 수정합니다(최대 20자). Enter 또는 칸 밖을 누르면 확정, Esc 는 취소, 빈 칸으로 확정하면 이전 이름으로 돌아갑니다. 중복 이름은 `이름 (2)` 로 구분됩니다.
- `×` 로 삭제, `+ 참가자 추가` 로 한 명씩 추가합니다. 전부 지우면 빈 목록이 유지되고(시작 버튼 비활성), `기본 목록으로` 버튼을 눌러야 기본 6명으로 돌아옵니다.
- `이름 붙여넣기로 일괄 추가` 에 한 줄에 한 명씩 붙여넣고 `일괄 추가` 를 누르면 한꺼번에 추가됩니다. 빈 줄은 무시되고 중복 이름은 `이름 (2)` 처럼 구분됩니다.
- 색은 입력 순서대로 자동 배정됩니다. 입력값은 브라우저 localStorage 에 저장되며, 저장이 안 되는 환경에서도 동작합니다. 예전 기본 목록(13명, 각 3개) 그대로 저장돼 있던 경우에만 새 기본 6명으로 바뀌고, 직접 편집한 데이터는 그대로 유지됩니다.
- 참가자가 많을수록 총 공 개수(참가자 수 x 공 개수)가 늘어 물리 연산·렌더링이 무거워집니다. 사용 중인 기기에서 부담되면 공 개수를 줄이세요.

## 크레딧

- 원본: https://github.com/egoavara/personal-pages/tree/main/pachinko 에서 가져왔으며, 원작자의 동의를 받아 사용합니다.
- 원본 저장소에는 라이선스 파일이 없으므로, 원본 코드와 에셋의 저작권은 원작자에게 있습니다.
- 원본의 `lucky-dice` 에서 단독 동작에 필요한 three.js 계열 파일과 일부 이미지/사운드를 함께 가져왔습니다.
- 이미지/사운드 에셋의 출처는 불명확합니다.

## 배포 시 주의 (캐시)

GitHub Pages 는 파일을 10분간 캐시하므로 `roster.js`/`sim.js` 를 고친 배포 전에는 `scripts/bump-version.sh` 를 실행해 `index.html` 의 `?v=` 버전을 올린 뒤 같이 커밋하세요. 회귀 테스트는 저장소 루트에서 `python3 -m http.server 8765` 를 띄우고 `node tests/regression.cjs` (playwright 필요) 로 실행합니다.
