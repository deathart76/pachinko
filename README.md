# pachinko

웹 기반 3D 파친코 게임입니다. (egoavara/personal-pages 기반 개인 수정판)

배포 주소: https://deathart76.github.io/pachinko/

## 크레딧

- 원본: https://github.com/egoavara/personal-pages/tree/main/pachinko 에서 가져왔으며, 원작자의 동의를 받아 사용합니다.
- 원본 저장소에는 라이선스 파일이 없으므로, 원본 코드와 에셋의 저작권은 원작자에게 있습니다.
- 원본의 `lucky-dice` 에서 단독 동작에 필요한 three.js 계열 파일과 일부 이미지/사운드를 함께 가져왔습니다.
- 이미지/사운드 에셋의 출처는 불명확합니다.

## 서드파티

- Rapier (Apache-2.0): `vendor/rapier2d.mjs`, 라이선스 `vendor/rapier2d.LICENSE`
- three.js (MIT): `vendor/three.*.js`, 라이선스 `vendor/three.LICENSE`
